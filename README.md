# 🐾 CatGirl Clock

Um aplicativo leve e estiloso de relógio em pixel art para Android, com suporte a widgets para a tela inicial e modo de descanso/carga (Daydream).

---

## 📱 Recursos

* **Widgets para Tela Inicial:**
  * **4x2:** Exibe hora e data completa em pixel art.
  * **4x1:** Formato panorâmico compacto.
  * **2x1:** Versão minimalista.
* **Modo de Carga (Daydream):** Funciona como proteção de tela com brilho reduzido enquanto o celular carrega.
* **Ocultar Ícone:** Opção na interface para esconder o app do menu de aplicativos.
* **Apoio ao Projeto:** QR Code PIX integrado na interface do aplicativo.

---

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** Java / Android SDK
* **Interface:** XML Layouts & Material Design Components
* **Componentes Android:** `AppWidgetProvider` & `DreamService` (Daydream API)
